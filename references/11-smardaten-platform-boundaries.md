# Smardaten 平台能力边界参考

> 用于 P2 主领域功能设计时，Agent 05 做 unsupported_design 必须逐项对照此文件。
> 标注规则：✅ 平台原生支持 | 🔧 需要配置/二开 | ❌ 平台不支持 | ⚠️ 需外挂/集成

---

## 1. 数据库与存储

| 能力项 | 支持度 | 说明 |
|--------|:---:|------|
| MySQL/PostgreSQL 关系型数据库 | ✅ | 平台标准数据源 |
| 信创数据库（达梦/人大金仓/神通） | ✅ | 2.1.7 信创数据库选型，需在平台配置数据源 |
| 表分区 | 🔧 | 批量数据表建议分区，需 DBA 配合 |
| 文件/附件存储（MinIO/OSS） | ✅ | 平台内置文件服务 |
| 大文件上传（>100MB） | ⚠️ | 需前端分片上传 + 后端合并，平台不直接支持 |
| 全文检索 | 🔧 | 需集成 Elasticsearch（外挂） |
| 读写分离/分库分表 | 🔧 | 需数据库层配置，非平台能力 |

## 2. 业务建模

| 能力项 | 支持度 | 说明 |
|--------|:---:|------|
| 表单设计器（拖拽建表） | ✅ | 平台核心能力 |
| 主子表/一对多关系 | ✅ | 子表组件原生支持 |
| 字段联动（选择A自动带出B） | ✅ | 表单设计器中配置字段联动规则 |
| 数据字典/下拉选项 | ✅ | 平台字典管理 |
| 计算公式/聚合字段 | ✅ | 支持简单公式，复杂逻辑需脚本 |
| 批量导入（Excel） | ✅ | 平台内置导入组件，支持校验+错误行提示 |
| 批量导出（Excel） | ✅ | 平台内置导出组件 |
| 附件上传/预览 | ✅ | 支持图片/PDF/Office 预览 |

## 使用规则

Agent 05 做 unsupported_design 时必须：

1. **逐功能对照**此表，标注平台是否支持
2. 标注为 `🔧 需二开` 或 `❌ 不支持` 的功能 → 写入 unsupported_design
3. 标注为 `⚠️ 需外挂` 的功能 → 写入 unsupported_design 并说明替代方案
4. 标注为 `✅ 原生支持` 的功能 → 正常设计
5. **不捏造平台能力** —— 此表中标记为 ❌/⚠️ 的能力，不得在设计中假设平台已提供
